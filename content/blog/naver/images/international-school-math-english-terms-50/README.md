## 🎨 SmartEditor 강조 적용 (Justin 수동)

본문 .md의 마크업 → SmartEditor:
- `**굵게**` → 자동 인식
- `「색상 강조: ...」` → 글자색 (Mathiter brand color)
- `『형광펜: ...』` → 형광펜 (노랑/청록)
- `【큰 글자: ...】` → 글자 크기 19~22px
- `> 인용` → 인용 박스

각 표시 emoji는 paste 후 **삭제**하고 강조 적용.
