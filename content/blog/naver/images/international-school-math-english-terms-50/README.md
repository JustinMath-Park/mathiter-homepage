## 🎨 HTML 자동 적용된 강조 스타일

본문 .html 안에 inline CSS로 다음이 모두 적용됨:

| 마크업 | 적용 |
|---|---|
| `**굵게**` | `<strong>` 자동 |
| `「색상 강조: ...」` | Mathiter 파랑 #3B82F6 + bold |
| `『형광펜: ...』` | 노란 형광펜 #FEF08A |
| `【큰 글자: ...】` | 20pt bold |
| `> 인용` | 파란 border + 옅은 파랑 배경 + italic |
| `---` | 회색 구분선 |
| `[이미지 N: ...]` | 점선 박스 + 📷 + "여기에 업로드" |
| URL | 자동 `<a>` 링크 (파랑 underline) |

→ Justin이 SmartEditor에서 강조 적용 작업 **거의 0건**. paste 한 번으로 모두 적용.
