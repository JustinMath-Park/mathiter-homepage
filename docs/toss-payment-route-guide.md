# 토스페이먼츠 결제경로 PPT 캡처 가이드

> **목적**: 토스페이먼츠 카드사 심사 통과를 위해 결제경로 PPT 작성.  
> **기반 자료**: 토스페이먼츠_홈페이지_결제경로_제작_가이드.pdf (2023-03-22 배포본).  
> **결제 대상 상품**: Mathiter Premium 1개월 이용권 — 34,900원 (단건 결제, V2 SDK / API 개별 키).

## 1. 사전 준비 — 결제 페이지 라이브 확인

새로 만든 결제 페이지가 라이브에 정상 배포됐는지 먼저 확인.

| URL | 확인 사항 |
|---|---|
| `mathiter.com/ko/pricing` | Mathiter Premium 34,900원 카드 + "결제하기" 버튼 |
| `mathiter.com/ko/payment/success` | (결제 후 자동 진입) 결제 승인 확인 + 영수증 |
| `mathiter.com/ko/payment/fail` | (결제 실패 시) 에러 코드·메시지 |

→ 라이브 안 됐으면 Vercel 빌드 완료까지 대기.

## 2. 캡처할 6단계 + 8가지 유의사항

### 6단계 순서

| # | 단계 | 캡처할 화면 |
|---|---|---|
| **1** | 가맹점 정보 (PPT 표지) | 텍스트로만 — 캡처 X |
| **2** | 홈페이지 하단정보 | 모든 페이지 푸터 (사업자 정보 박스 잘 보이게) |
| **3** | 환불규정 | `mathiter.com/ko/refund` 페이지 |
| **4** | 로그인 / 회원가입 | Mathiter는 비회원 결제이므로 생략 또는 main-portal 로그인 화면 |
| **5** | 상품선택 / 구매과정 | `mathiter.com/ko/pricing` 페이지 + "결제하기" 클릭 → 토스 결제수단 선택 화면 |
| **6** | 카드 결제경로 | 신용카드 선택 → 카드사 선택 (드롭다운) + **비씨카드 인증 화면 필수** |

### 8가지 유의사항 (모든 캡처 공통)

| # | 규칙 | 어떻게 |
|---|---|---|
| **1** | **PPT 형식 필수** (PDF X) | `.pptx`로 저장 |
| **2** | **북마크바 없이 도메인 보이게** | Chrome 북마크바 숨김(`⌘ + Shift + B`), 주소창에 `mathiter.com` 보이게 |
| **3** | **PC 시간 함께 캡처** | macOS는 우상단 메뉴바, Windows는 우하단 작업표시줄 시계 포함 |
| **4** | 상품/서비스 명칭·이미지·설명·금액·결제 흐름 모두 확인 | 누락 X |
| **5** | **테스트 계정** + 로그인 과정 캡처 | Mathiter는 비회원 결제라 해당 X |
| **6** | **테스트 결제창 OK** | 라이브 키 없어도 테스트 키로 가능 ✅ |
| **7** | 안심키인 결제창 없으면 생략 OK | 해당 X |
| **8** | **비씨 카드 인증 화면까지** 필수 | 카드사 선택 시 비씨카드 흐름 별도 캡처 |

## 3. 단계별 상세 캡처 가이드

### Slide 1 — 가맹점 정보 (표지)

PPT 첫 슬라이드. 캡처 없음. 텍스트로:

```
(1) 상호명      : 엘리코바 (Elicova)
(2) 사업자번호  : 710-05-03676
(3) URL         : https://mathiter.com
(4) Test ID     : (비회원 결제 — 해당 없음)
(5) Test PW     : (해당 없음)
```

비회원 결제라는 점 PPT 슬라이드에 명시.

### Slide 2 — 하단정보 캡처

캡처 페이지: `mathiter.com/ko/pricing` (또는 다른 페이지 어디든 푸터 동일)

캡처 영역: **푸터 전체 + 도메인 주소 + PC 시간** 같이.

확인할 정보:
- ✅ 상호명: 엘리코바 (Elicova)
- ✅ 대표자명: 박세준
- ✅ 사업자등록번호: 710-05-03676
- ✅ 통신판매업 신고번호: 제2026-용인처인-01131호
- ✅ 사업장 주소: 경기도 용인시 처인구 이동읍 기흥단지로 579-1, 1동 303호 (라센트라)
- ✅ 전화번호: 010-5187-8080

> 푸터의 사업자정보 박스가 작은 글씨라, 캡처 시 푸터 부분을 확대해서 함께 첨부하면 좋음.

### Slide 3 — 환불규정 캡처 (무형상품)

캡처 페이지: `mathiter.com/ko/refund`

캡처 영역: 페이지의 환불 관련 핵심 조항이 보이는 부분.

→ Mathiter는 **무형상품**이므로 `B. Mathiter 학습앱 구독 환불 정책` 섹션 중심으로 캡처.

토스 PDF 9페이지 "무형상품 예시"와 비슷한 형식으로 캡처되면 OK.

### Slide 4 — 로그인 / 회원가입 캡처

Mathiter Premium 결제는 **비회원 결제**(누구나 결제 가능)로 설정되어 있어서, 이 단계는 **"생략"** 또는 다음 슬라이드로 대체:

```
※ Mathiter Premium 결제는 비회원 구매가 가능하여
   로그인/회원가입 단계가 필요하지 않습니다.
   결제 후 영수증에 기재된 이메일로 활성화 안내가 전송됩니다.
```

→ 토스 PDF 4페이지 유의사항 5번에서 "비회원 구매 시 생략 가능" 명시.

### Slide 5 — 상품선택 / 구매과정 캡처 (3개 슬라이드)

#### Slide 5-1: 가격 페이지 (상품 카드)

캡처 페이지: `mathiter.com/ko/pricing`

캡처 영역:
- ✅ 페이지 헤더 ("Mathiter Premium 구독")
- ✅ 상품 카드 — 상품명·가격(34,900원)·이용 기간·포함 사항
- ✅ "결제하기" 버튼 (강조 — 박스 또는 빨간 동그라미)
- ✅ 도메인 주소 + PC 시간

#### Slide 5-2: 결제 안내 박스

같은 페이지에서 스크롤 다운 후 결제 안내 박스가 보이게 캡처:
- "본 상품은 디지털 콘텐츠 1개월 이용권입니다..."

"결제하기" 클릭 후 뜨는 토스 결제창 캡처:

- 토스페이 / 네이버페이 / 카카오페이 등 간편결제
- **신용·체크카드 선택 상태**로 캡처 (다음 단계로 가는 흐름)

### Slide 6 — 카드 결제경로 캡처 (2개 슬라이드)

비씨/현대/삼성/롯데/하나/우리/신한/국민/농협 등 카드사 리스트 모두 보이게.

#### Slide 6-2: 비씨 카드 인증 화면 (필수)

토스 PDF 16페이지에 강조된 부분.

비씨 카드 선택 → "다음" 클릭 → 페이북 또는 ISP 인증 화면 캡처.

토스 PDF에 정확한 예시 있음 — 같은 형식으로 캡처.

## 4. 캡처 팁

### macOS

| 단축키 | 기능 |
|---|---|
| `⌘ + Shift + 3` | 전체 화면 캡처 |
| `⌘ + Shift + 4` | 선택 영역 캡처 |
| `⌘ + Shift + 5` | 캡처 도구 (전체/창/영역, 옵션) |
| `⌘ + Shift + B` (Chrome) | 북마크바 숨김 |
| 우상단 메뉴바 시계 | PC 시간 같이 캡처되는지 확인 |

### Chrome 브라우저 셋업

캡처 전:
1. **북마크바 숨김** — `⌘ + Shift + B`
2. **시크릿 모드 사용 권장** — 확장 프로그램 영향 없음
3. **개발자 도구 닫기** (`⌘ + Option + I`로 토글)
4. **창 크기**: 1200~1440px 폭 권장 (모바일 캡처는 별도)
5. **줌**: 100% 표준 (`⌘ + 0`)

### 테스트 결제 카드 정보

토스 테스트 환경에서 사용 가능한 가상 카드:

| 항목 | 값 |
|---|---|
| 카드번호 | `4330-1234-1234-1234` |
| 유효기간 | `12/30` |
| CVC | `000` |
| 비밀번호 (앞 2자리) | `00` |

> 실제 결제 안 됨, 토스 테스트 환경 전용. 라이브 키로 바뀌면 실제 카드만 작동.

## 5. PPT 작성 순서

1. **Mathiter Premium 1개월권 결제 시도** (테스트 카드로)
2. 위 6단계 + 8 유의사항에 따라 화면 캡처 (총 10~15장)
3. PowerPoint 또는 Keynote로 PPT 작성:
   - 슬라이드 1: 가맹점 정보 (텍스트)
   - 슬라이드 2: 하단정보 캡처
   - 슬라이드 3: 환불규정 캡처
   - 슬라이드 4: 비회원 결제 안내 (텍스트)
   - 슬라이드 5-1: 가격 페이지
   - 슬라이드 5-2: 결제 안내 박스
   - 슬라이드 5-3: 토스 결제수단 선택
   - 슬라이드 6-1: 카드사 선택
   - 슬라이드 6-2: 비씨 카드 인증
4. **.pptx 형식으로 저장** (.pdf 변환 금지)
5. 토스 계약담당자 이메일로 전달

## 8. 트러블슈팅

### 결제창이 안 뜨면
- `.env.local`의 `NEXT_PUBLIC_TOSS_CLIENT_KEY` 등록 확인
- 브라우저 콘솔 (F12) → 에러 메시지 확인
- 시크릿 모드에서 다시 시도

### "결제 승인 실패" 페이지로 가면
- `.env.local`의 `TOSS_SECRET_KEY` 등록 확인
- Vercel 배포 환경변수에도 등록됐는지 확인
- Vercel 배포 로그 (Functions 탭) 확인

### 비씨 카드 선택이 안 보이면
- 토스 테스트 환경에서는 카드사 선택이 자동 노출됨
- 결제수단 선택 → 신용·체크카드 → 카드사 선택 단계 진입
- 만약 안 보이면 토스 결제창 모드 확인 (`flowMode: "DEFAULT"`)
