> **목적**: 토스페이먼츠 카드사 심사 통과를 위해 결제경로 PPT 작성.
> **기반 자료**: 토스페이먼츠_홈페이지_결제경로_제작_가이드.pdf.
> **결제 대상 상품**: Mathiter Premium 1개월 이용권 — 34,900원 (단건 결제, V2 SDK / API 개별 키).
> **v2 변경점 (2026-05-20)**:
> 1. **비회원 결제 제거** → 회원만 결제 가능. 로그인/회원가입 유저 저니 캡처 필수.
> 2. 토스 가이드 PDF 16페이지 (8번 유의사항) 재확인 — **각 카드사 인증 화면까지 캡처**해야 함. 비씨카드는 무조건 필수.

## 3. 토스 가이드 PDF 16페이지 — 8번 유의사항 (재해석)

> "비씨 카드사는 특히 결제 직전까지의 확인이 필요하기에 **각 카드사 인증 화면까지 캡처해야 해요. 비씨카드사에 대한 캡처는 필수예요.**"

**해석**:
- **비씨카드**: 결제 직전(페이북 인증)까지 무조건 캡처 — 필수
- **다른 카드사**: 본인이 사용/보유한 카드사들도 인증 화면까지 캡처해 제출하는 게 안전
- 토스가 심사 진행하면서 "X 카드사 인증 화면이 누락됐다"라고 보완 요청을 줄 수 있음

1. **(비로그인) `/pricing` 진입** → 가격 카드 + 로그인 안내 배너 + "로그인하고 결제하기" 버튼

5. "회원가입하고 결제하기" 클릭 → `/pricing`으로 자동 복귀
6. 결제 페이지 — 상단에 "**[이메일] 계정으로 결제됩니다**" 노출 + "결제하기" 버튼 활성

→ 캡처: 1, 3, 4, 6 (4장)

**시나리오 2 (로그인 흐름)**: 기존 회원

| **8** | **각 카드사 인증 화면까지** | 비씨카드 무조건 + 가능한 다른 카드사 추가 |

## 6. PPT 작성 순서 (v2)

1. **Mathiter Premium 1개월권 결제 시도** (실제 BC카드 + 보유 다른 카드들)
2. 위 단계 흐름에 따라 화면 캡처 (15~25장 예상)
3. python-pptx 스크립트로 생성 (`/tmp/generate_toss_ppt.py`)
   - 표지
   - 푸터
   - 환불 2장
   - 약관 4장
   - 개인정보 2장
   - **로그인/회원가입 흐름 4장 (신규)**
   - 가격 카드 + 결제 안내 박스 2장
   - 결제 흐름 (수단 선택 + 카드 입력) 2장
   - **카드사 인증 (비씨 3장 + 추가 카드사들)**
   - 결제 완료 + 영수증 2장
4. **.pptx 형식으로 저장** (.pdf 변환 금지)
5. 토스 계약담당자 이메일로 전달

## 8. 트러블슈팅

### 로그인이 안 되면
- Firebase Console (mathiter-prod) → Authentication → Sign-in method → Email/Password + Google 활성화 확인
- Vercel 환경변수에 `NEXT_PUBLIC_FIREBASE_API_KEY` 등 6개 키 등록 확인
- 브라우저 콘솔 (F12) 에러 메시지 확인

### Google 로그인 팝업이 차단되면
- Chrome 팝업 차단 해제
- 시크릿 모드에서 다시 시도

### 결제창이 안 뜨면
- 로그인 안 된 상태에서 결제 버튼 누른 경우 → 로그인 페이지로 자동 이동됨 (정상)
- 로그인 된 상태에서도 안 뜨면 → `.env.local`의 `NEXT_PUBLIC_TOSS_CLIENT_KEY` 등록 확인

### 비씨카드 결제 흐름이 안 보이면
- 토스 테스트 환경에서 카드사 선택 → 비씨카드(BC) 선택 → 페이북 인증 진입
- 실제 비씨카드로 페이북 인증 가능
